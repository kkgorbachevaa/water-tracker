# Water Tracker

Water Tracker - проект для отслеживания потребления воды

## Реализовано

- Стартовый экран с вводом дневной цели в миллилитрах
- Значение цели по умолчанию - 2000 мл
- Проверка цели перед запуском: принимается положительное целое число
  в безопасном числовом диапазоне JavaScript
- Сообщение об ошибке и выделение некорректного поля
- Очистка ошибки при редактировании значения
- Запуск сессии кнопкой «Начать» или клавишей Enter / Return
- Основной экран с отображением выбранной цели
- Модель данных для сессии, записей о воде и выбора емкости
- Функция расчета дневного прогресса по данным сессии: выпитый объем, остаток, процент выполнения цели и уровень воды в бутылке
- Остаток не становится отрицательным, прогресс может превышать 100%, уровень бутылки ограничен диапазоном 0–100%
- Показатели вычисляются из цели и истории без отдельного хранения в сессии

## Текущие ограничения

- Сессия хранится в памяти приложения и сбрасывается при обновлении страницы
- Добавление воды и отображение истории пока не реализованы
- Расчеты прогресса реализованы отдельно и пока не подключены к интерфейсу

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить приложение в режиме разработки:

```bash
npm run dev
```

## Проверки

Запустить все тесты (компонентные и юнит-тесты):

```bash
npm test
```

Запустить только юнит-тесты расчетов:

```bash
npm test -- src/utils/calculateDailyProgress.test.ts
```

Запустить тесты с автоматическим перезапуском при изменении файлов:

```bash
npm run test:watch
```

Тесты проверяют:

- Запуск с целью 2000 мл по умолчанию
- Сохранение введенной цели и отправку формы через Enter
- Отклонение пустого, нулевого, отрицательного и дробного значения
- Исправление ошибки и последующий успешный запуск сессии
- Начальные показатели при пустой истории
- Суммирование нескольких записей и прогресс до достижения цели
- Достижение и превышение цели: нулевой остаток и уровень бутылки, возможность прогресса выше 100%
- Расчеты для другой дневной цели и дробные проценты

Запустить линтер:

```bash
npm run lint
```

Выполнить production-сборку:

```bash
npm run build
```
