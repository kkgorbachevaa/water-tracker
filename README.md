# Water Tracker

Water Tracker - проект для отслеживания потребления воды

## Реализовано

- Стартовый экран с вводом дневной цели в миллилитрах
- Значение цели по умолчанию - 2000 мл
- Проверка цели перед запуском: принимается положительное целое число
  в безопасном числовом диапазоне JavaScript
- Сообщение об ошибке и выделение некорректного поля
- Очистка ошибки при редактировании значения
- Запуск сессии кнопкой «Начать» или клавишей Enter / Return
- Основной экран с отображением дневной цели, выпитого объема, остатка и процента выполнения
- Форматирование процента: максимум один знак после запятой, с использованием русской десятичной запятой
- Адаптивное расположение карточек основного экрана
- Модель данных для сессии, записей о воде и выбора емкости
- Функция расчета дневного прогресса по данным сессии: выпитый объем, остаток, процент выполнения цели и уровень воды в бутылке
- Остаток не становится отрицательным, прогресс может превышать 100%, уровень бутылки ограничен диапазоном 0–100%
- Показатели вычисляются из цели и истории без отдельного хранения в сессии
- Добавление воды через выбор типа емкости, объема и выпитой доли
- Типы емкостей: стакан, чашка, термостакан и бутылка
- Объемы: 200, 300, 400 и 500 мл; доли: четверть, половина, три четверти и вся емкость
- Предварительный расчет добавляемого объема
- Создание записей с уникальным идентификатором, временем и источником
- Сохранение выбора формы после добавления и последней добавленной емкости в сессии
- Обновление прогресса после каждого добавления, включая превышение цели
- Управление формой с клавиатуры

## Текущие ограничения

- Сессия хранится в памяти приложения и сбрасывается при обновлении страницы
- Ручной ввод объема, отображение истории и отмена добавления пока не реализованы
- Основной экран пока использует узкую одноколоночную компоновку, поэтому на десктопе может требоваться вертикальная прокрутка
- Визуальная бутылка и анимации пока не реализованы

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить приложение в режиме разработки:

```bash
npm run dev
```

## Проверки

Запустить все тесты (компонентные и юнит-тесты):

```bash
npm test
```

Запустить только юнит-тесты расчетов:

```bash
npm test -- src/utils/calculateDailyProgress.test.ts
```

Запустить тесты с автоматическим перезапуском при изменении файлов:

```bash
npm run test:watch
```

Запустить только компонентные тесты основного экрана:

```bash
npm test -- src/components/TrackerScreen.test.tsx
```

Запустить тесты добавления воды: создание записи, форму и обновление сессии:

```bash
npm test -- src/utils/createContainerEntry.test.ts src/components/AddWaterForm.test.tsx src/App.addWater.test.tsx
```

Тесты проверяют:

- Запуск с целью 2000 мл по умолчанию
- Сохранение введенной цели и отправку формы через Enter
- Отклонение пустого, нулевого, отрицательного и дробного значения
- Исправление ошибки и последующий успешный запуск сессии
- Начальные показатели при пустой истории
- Суммирование нескольких записей и прогресс до достижения цели
- Достижение и превышение цели: нулевой остаток и уровень бутылки, возможность прогресса выше 100%
- Расчеты для другой дневной цели и дробные проценты
- Отображение цели и начального прогресса для разных дневных целей
- Отображение показателей по записям, включая дробный процент, достижение и превышение цели
- Обновление показателей компонента при передаче новой сессии
- Создание записей с рассчитанным объемом, идентификатором, временем и источником
- Предварительный расчет для всех доступных долей
- Отправку формы, сохранение выбора и повторное добавление
- Управление формой с клавиатуры
- Суммирование последовательных добавлений и обновление прогресса
- Добавление после достижения и превышения цели
- Корректное повторное добавление в StrictMode

## Ручная проверка

1. Запустить приложение командой `npm run dev`.
2. Начать сессию с целью 2000 мл. Проверить начальные показатели: выпито 0 мл, осталось 2000 мл, выполнение цели 0%.
3. Добавить воду с начальным выбором: стакан 200 мл целиком. Проверить: выпито 200 мл, осталось 1800 мл, прогресс 10%.
4. Выбрать 300 мл и половину. Предпросмотр должен показать 150 мл, выпитый объем до отправки остается 200 мл. Добавить воду: итог 350 мл, остаток 1650 мл, прогресс 17,5%.
5. Повторить добавление без изменения выбора. Проверить сохранение выбора и итог: 500 мл, остаток 1500 мл, прогресс 25%.
6. Обновить страницу и начать с целью 200 мл. Дважды добавить по 200 мл: итог 400 мл, остаток 0 мл, прогресс 200%.
7. Проверить выбор через Tab и стрелки, отправку через Enter на кнопке.
8. Проверить широкое окно и ширину 375 и 320 px: подписи помещаются, элементы не перекрываются, горизонтальной прокрутки нет, кнопка доступна при вертикальной прокрутке.
