# Water Tracker

Water Tracker - проект для отслеживания потребления воды

На текущем этапе подготовлен минимальный каркас приложения без продуктовой логики

## Стек

- React
- TypeScript
- Vite
- CSS Modules
- Oxlint

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить приложение в режиме разработки:

```bash
npm run dev
```

## Проверки

Запустить линтер:

```bash
npm run lint
```

Выполнить production-сборку:

```bash
npm run build
```
